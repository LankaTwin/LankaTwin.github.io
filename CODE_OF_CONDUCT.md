# Code of conduct

LankaTwin follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, assume good faith, and keep discussion about the work. Contributors writing in Sinhala, Tamil or English are equally welcome.
Report problems privately to the maintainer via the email on the GitHub profile of @AshenWijesingha.
